# Rotatev2

旋转方块小游戏的骰子轻量版。当前快照：2026-09-30。

## 运行

本项目是静态网页，无需安装前端依赖。

在仓库目录运行：

```sh
python -m http.server 5188 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:5188/ 。本仓库通过 GitHub Pages 发布在线版本。

## 在线游玩

GitHub Pages 地址：https://silvera0218.github.io/Rotatev2/

网页直接从本仓库根目录部署。

## 当前玩法

- 填满轮廓得分，以每关目标分数通关；支持五关挑战与无尽模式。
- 每次通关随机生成三颗骰子，可混合四面、六面、八面和十二面骰。按当前组合对应的总点数区间，进入商店、道具补给、Buff 或方块改造。
- 奖励区间用正方形像素图标卡片走马灯展示；投掷时加速，结果确定后居中高亮。
- 每关可免费换一组骰子，投掷前后共用一次，进入奖励页后不能换。
- 道具补给、Buff、方块改造均三选一。Buff 与方块改造提供一次免费刷新，随后最多三次模拟广告刷新，每次等待 2 秒。
- 商店随机生成八个货位，可分类查看，点击商品打开购买详情。
- 未使用的普通道具和方块改造道具可跨关保留，新奖励叠加到库存。道具用完后移出栏位；新一局恢复初始库存。
- 方块改造道具在落地前改变整块材质；铲子移除上一次投放的存留方块。
- 保存与继续使用浏览器本地存储。

电脑操作：方向键或 A/D 移动，R 或上方向键旋转，空格投放。手机使用屏幕按钮。

## 修改与重建

- `lite-rules.js`：轻量版规则。
- `lite-integration.js`：界面和原引擎的接入。
- `lite-ui.css`、`lite-integration.css`：界面样式。
- `lite-dice.js`、`lite-transition.js`：骰子和页面转场。
- `lite-dice-routes.json`：不同骰型组合的奖励区间。
- `assets/`：图标、图片及相关制作源文件。
- `source/base-game.html`：重建所需的原版引擎页面。

修改接入文件或骰子区间后运行：

```sh
python build-copy.py
```

该命令重建根目录 `index.html`。外部脚本、样式、图片修改直接生效。

规则测试（需要 Node.js，无需额外 npm 包）：

```sh
node --test tests/lite-rules.test.mjs
```
